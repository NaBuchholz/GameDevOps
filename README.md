# Getting Started

## Before cloning

### Windows
1. Install Git from https://git-scm.com/download/win
2. Install Git LFS from https://git-lfs.com

### Linux
1. Install Git and Git LFS using your package manager:

   **Arch:**
   ```
   sudo pacman -S git git-lfs
   ```
   **Ubuntu:**
   ```
   sudo apt install git git-lfs
   ```
   **Fedora:**
   ```
   sudo dnf install git git-lfs
   ```

---

## Cloning the repository

```
git clone <repository-url>
```

---

## After cloning

### Windows
Run `setup.bat` by double-clicking it or from the terminal:
```
setup.bat
```

### Linux
Run `setup.sh` from the terminal:
```
sh setup.sh
```

---

That's it. You're ready to go.
